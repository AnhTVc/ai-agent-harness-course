# Video 01 Presentation

## Open the presentation

Open `index.html` in a modern browser. The slides use local assets and require
no package installation or Internet connection.

## Controls

- Use **Left / Right**, **Page Up / Page Down**, **Home / End**, or the on-page
  controls to navigate.
- Select **Fullscreen** when presenting.
- Use the browser print dialog to print or save a PDF.

## Supplied source images

`assets/source-images/` preserves the 12 supplied slide images. The files are
named by the page number printed on each image. The set contains pages 00 and
02–12; page 01 was not supplied.

## Illustrations

`assets/illustrations/` contains the lesson's reusable visual assets:

- `ai-agent-hero.png` — abstract hero artwork.
- `agent-architecture.png` — conceptual runtime and agent illustration.
- `tool-execution.png` — tool-execution illustration.

The supplied slide images remain unchanged. The English lesson README uses the
architecture illustration alongside runnable source maps and diagrams.
