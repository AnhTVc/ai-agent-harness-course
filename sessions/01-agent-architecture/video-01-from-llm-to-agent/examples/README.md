# Offline execution evidence

The finished JSON examples are generated by the Python engine with its explicit
rule-based stand-in. They are not traces of real LLM inference, answer-quality
benchmarks, or claims about an actual company.

- agent-offline.json: successful lookup and observation feedback.
- chatbot-offline.json: one tool-free response.
- direct-answer-offline.json: greeting answered without a lookup.
- empty-result-offline.json: missing evidence remains explicit.
- missing-executor-offline.json: request exists but no handler succeeds.
- missing-observation-offline.json: results are withheld from model context.
- workflow-offline.json: fixed code path with zero model calls.
- debugger-at-tool-breakpoint-offline.json: live session snapshot before tool
  execution, with a pending request and zero executed tools.

Run IDs and timing values vary. Regenerate finished traces with the commands in
the lesson README. The paused debugger snapshot is generated by DebugSession
and does not call the pending handler.
