# Verification and limits

This report records checks of the local teaching artifact, not model quality.

## Automated checks

- 64 Python tool, runtime, debugger, HTTPS, HTTP integration, and package tests
  pass with pytest.
- Python line coverage is 91% across the agent-lab source.
- Black formatting checks pass for Python; Prettier checks pass for browser
  assets and Markdown guides.
- Node.js syntax validation passes for the browser module.
- Python bytecode compilation passes for source, entry point, and tests.
- Seven finished JSON examples and one paused debugger snapshot were generated by the offline runtime.
- Package checks validate local Markdown links, graph-node source references,
  English-only Markdown guides, the README source map, and secret/generated-file
  ignore rules. Supplied slide images remain unchanged.

Behavior checks cover paused creation, single-step execution, breakpoint hits,
request edits, provider and tool errors, context snapshots, cooperative pause
and stop, isolated sessions, HTTP origin/host restrictions, bounded requests,
and arbitrary-path denial. The Ollama wire adapter uses a fake HTTP response
for its contract check.

## Browser verification

The local debugger was exercised at a 582 × 720 browser viewport. A run created
from the offline **Weather · Hanoi** preset paused before tool execution with
zero tool calls. The request showed `search_weather(location="Hanoi, Vietnam")` and
the argument editor exposed `location`. One Step called the live Open-Meteo
geocoding and current-conditions endpoints; the result contained a matched
place, observation time, metric units, current values, and source attribution.
The run then paused before appending the observation to context. Selecting the
result event highlighted the actual `_search_weather` implementation in
`tools.py`. A separate live lookup succeeded from the local Python runtime.

## Explicit limits

The optional Ollama endpoint was unavailable during the previous verification.
No live-model inference, answer-quality evaluation, latency benchmark, or
comparative agent-quality claim is reported. Offline timings describe synthetic
fixture operations only. Search is keyword-based and does not implement RAG.

Pause and Stop are cooperative. An in-flight provider request must return or
time out before the next boundary is prevented. Sessions live in server memory,
expire when idle, and are not persistent conversation history. Restarting the
server clears them.

This course folder does not contain a Git repository or remote configuration.
The source is packaged for handoff so it can be connected to the intended
remote and pushed by the course owner.
